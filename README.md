# Sajjad Gheysari Arani

### Technical Systems Builder & Software Architect

I build and architect software systems rather than specializing in a single programming language.

My work focuses on:

- Software architecture and system design
- Backend and API architecture
- Web applications and digital products
- Database and data modeling
- Infrastructure, networking, and deployment
- System integration and third-party services
- Security, reliability, and scalability
- AI-assisted software development

I work across different programming languages and technologies depending on the problem, but my primary strength is not a specific language — it's understanding how the whole system should be designed, connected, deployed, and maintained.

### What I do

I take an idea from:

**Concept → Architecture → Implementation → Integration → Deployment → Production**

and turn it into a working system.

### Engineering Approach

I care about:

- Clean architecture
- Practical and maintainable systems
- Security by design
- Performance and reliability
- Automation
- Extensibility
- Clear separation of responsibilities

I don't define myself by one stack.

I define myself by the systems I can design and build.
